# Data Cleaning Report

Generated by `src/clean_data.py`. Covers 5 Karnataka rainfall CSVs (2020–2025).

## What changed in the report logic

- **2025 geo-inference mismatch list** is filtered to genuine disagreements only:
  - Different district or different taluk between 2025 and the majority vote from 2020–2023.
  - Excluded: case-only taluk differences (e.g. `hosakote` vs `HOSAKOTE`), hobli-named-as-taluk rows (e.g. `chikballapura` under `CHIKKABALLAPURA`), UNKNOWN-vs-empty taluk, and same-name district/taluk header rows.
  - Deduped per (2025 taluk, majority taluk) pair.
- Per-year tables now leave Summary/region rows dropped as `—/—` (the drop is applied across all years, not per year).

## Interpreting the mismatch table

Each row is one representative taluk whose 2025 placement differs from the majority of other years. “Votes” is `majority_count / total_votes_from_2020_2023`. Rows with a majority count below 2 are not shown.
